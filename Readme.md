Данный репозиторий представляет собою тестовое задание "Django + Stripe".

[Техническое задание](test_task.docx)

Для запуска воспользуйтесь:

    docker-compose -f docker-compose.dev.yml up --build -d


Логика:

1) Зайдите в админ панель /admin
2) Создайте товары, затем создайте заказ. (Также можете создать скидку и налог).
3) Скопируйте id созданного заказа и откройте /items/order/{id}
4) Оплатите заказ :)
